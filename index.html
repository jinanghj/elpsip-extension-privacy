ELPSIP 출원서 작성 — 개인정보처리방침

시행일 2026년 11월 12일 · English

이 방침은 Chrome 확장프로그램 ELPSIP 출원서 작성(이하 “확장”)이 사용자의 정보를 어떻게 다루는지 설명합니다. 확장은 ELPSIP 사내 사건관리 시스템(db.elpsip.com)에 로그인한 직원이 상표출원서 초안을 만들 때 쓰는 사내 업무 도구입니다.

1. 다루는 정보

사용자가 사건 상세 화면에서 확장 아이콘을 누를 때, 그 화면과 연결된 출원인 상세 화면에서 아래 항목만 읽습니다.

사건정보관리번호, 상표명, 상표유형, 상품류·지정상품, 등록대상 입력방법
출원인 정보출원인 이름, 특허고객번호, 포괄위임등록번호
상표견본사건 화면에 첨부된 상표견본 이미지
사용자 입력팝업에서 사용자가 수정한 상품류·지정상품

방문 기록, 다른 웹사이트의 내용, 쿠키·비밀번호 등 인증 정보, 위치 정보는 읽거나 저장하지 않습니다.

2. 이용 목적

위 정보는 상표출원서 초안 파일(PDF·BIB)과 상표견본 JPG를 만드는 데에만 사용합니다. 다른 목적으로 이용하지 않습니다.

3. 처리 방법

  • 정보는 사용자의 PC 안에서만 처리합니다. 개발자나 제3자의 서버로 보내지 않습니다.
  • 출원인 상세 화면과 견본 이미지는 같은 사이트(db.elpsip.com)에서 사용자의 현재 로그인 상태로 읽습니다.
  • 만든 파일은 사용자가 직접 고른 PC 폴더에만 저장합니다. 이를 위해 사용자 PC에 설치한 저장 도우미 프로그램과 Chrome Native Messaging으로 통신하며, 이 도우미도 외부와 통신하지 않습니다.
  • 인공지능(LLM)·분석·광고 서비스를 사용하지 않습니다.

4. 보관 기간

확장은 읽은 정보를 브라우저 저장소에 보관하지 않으며, 팝업 창을 닫으면 메모리에서 사라집니다. 사용자가 저장한 PDF·BIB·JPG 파일은 사용자 PC에 남으며 사용자가 직접 관리·삭제합니다.

5. 제3자 제공 및 판매

정보를 제3자에게 제공하거나 판매하지 않습니다. 확장의 목적과 관계없는 용도, 신용도 판단, 대출 심사에 사용하지 않습니다.

6. Chrome 웹스토어 사용자 데이터 정책 준수

이 확장이 받은 정보의 사용은 제한적 사용(Limited Use) 요건을 포함한 Chrome 웹스토어 사용자 데이터 정책을 준수합니다.

7. 방침 변경

방침을 바꾸면 이 페이지에 새 시행일과 함께 게시합니다.

ELPSIP 출원서 작성 — Privacy Policy

Effective November 12, 2026

This policy explains how the Chrome extension ELPSIP 출원서 작성 (“the extension”) handles user data. The extension is an internal tool for ELPSIP staff who are signed in to the company’s case management system (db.elpsip.com) and need to prepare Korean trademark application drafts.

1. Data the extension handles

Only when the user clicks the extension icon on a case detail page, the extension reads the following from that page and from the linked applicant detail page:

Case informationDocket number, mark name, mark type, class and designated goods, representation type
Applicant informationApplicant name, KIPO customer number, general power of attorney number
Mark specimenThe trademark specimen image attached to the case page
User inputClass and goods edited by the user in the popup

The extension does not read or store browsing history, content of other websites, cookies, passwords or other authentication data, or location.

2. Purpose

The data is used only to generate the draft application files (PDF and BIB) and the specimen JPG. It is not used for any other purpose.

3. How data is processed

  • All processing happens on the user’s computer. No data is sent to the developer or to any third-party server.
  • The applicant detail page and specimen image are fetched from the same site (db.elpsip.com) using the user’s existing session.
  • Generated files are saved only to a folder the user chooses. To do this the extension talks, via Chrome Native Messaging, to a small saving helper installed on the user’s PC. The helper does not communicate with any network service.
  • No AI/LLM, analytics or advertising services are used.

4. Retention

The extension does not keep the data in browser storage; it is discarded from memory when the popup window closes. Files the user saves remain on the user’s computer under the user’s control.

5. Sharing and sale

Data is not sold or transferred to third parties, is not used for purposes unrelated to the extension’s single purpose, and is not used to determine creditworthiness or for lending purposes.

6. Chrome Web Store User Data Policy

The use of information received by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

7. Changes

Any changes will be posted on this page with a new effective date.
